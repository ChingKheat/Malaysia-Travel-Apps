# Reference index attribution

Generated image feature vectors. The app uses the vectors for similarity scoring.

The feature extractor is [MediaPipe MobileNet V3 Large](https://storage.googleapis.com/mediapipe-models/image_embedder/mobilenet_v3_large/float32/1/mobilenet_v3_large.tflite).
The model metadata declares Apache License 2.0. See [MODEL_LICENSE.txt](MODEL_LICENSE.txt).

Food features from ParkingBot Dataset’s
[Malaysian Food Image Recognition, version 7](https://universe.roboflow.com/parkingbot-dataset/malaysian-food-image-recognition/dataset/7),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Images were cropped and encoded as feature vectors.

Landmark photos were resized and encoded as feature vectors.
