# Recognition sample images

`petronas.jpg` is the photo **Petronas Twin Towers at Night in Kuala Lumpur,
Malaysia**, from [Good Free Photos](https://www.goodfreephotos.com/malaysia/kuala-lumpur/petronas-twin-towers-at-night-kuala-lumpur-malaysia.jpg.php).
The source lists it as [CC0 / Public Domain](https://creativecommons.org/publicdomain/zero/1.0/).
The downloaded JPEG is unchanged; the UI uses `BoxFit.cover` for its display.

The other sample images were already present in the workspace before this UI
update.
